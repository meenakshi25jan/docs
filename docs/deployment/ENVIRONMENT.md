# Environment variables

## Render API (`ai-english-teacher-api`)

| Variable | Required | Example / notes |
|----------|----------|-----------------|
| `DATABASE_URL` | Yes | `postgresql://...?sslmode=require` |
| `JWT_SECRET_KEY` | Auto | Generated by Render |
| `OPENAI_API_KEY` | For AI | Groq key |
| `ENVIRONMENT` | Yes | `production` (in render.yaml) |
| `SKIP_MIGRATIONS` | Yes | `true` — use migrate script |
| `CORS_ORIGINS` | Yes | Includes web Render URL |
| `AI_PROVIDER` | Yes | `openai` |
| `OPENAI_BASE_URL` | Yes | Groq OpenAI-compatible URL |

## Render Web (`ai-english-teacher-web`)

| Variable | Required | Value |
|----------|----------|--------|
| `NODE_VERSION` | Yes | `20` |
| `NEXT_PUBLIC_API_URL` | Yes | `/api/v1` |
| `API_PROXY_URL` | Yes | `https://ai-english-teacher-api.onrender.com` |

## GitHub Actions

| Secret | Used in |
|--------|---------|
| `DATABASE_URL` | Deploy migrations |
| `RENDER_DEPLOY_HOOK_*` | Deploy triggers |

Never commit secrets. Use Render dashboard and GitHub Secrets.

## Validation

- CI: `validate_render_config.py`
- Deploy: missing `DATABASE_URL` skips migrations (logged)
