# Environment variables

## Render API (`ai-english-teacher-api`)

| Variable | Required | Value / notes |
|----------|----------|----------------|
| `DATABASE_URL` | **Yes** | Neon URL with `?sslmode=require` |
| `JWT_SECRET_KEY` | Auto | Generated by Render blueprint |
| `OPENAI_API_KEY` | For AI | Groq or OpenAI key |
| `ENVIRONMENT` | Yes | `production` (set in `render.yaml`) |
| `SKIP_MIGRATIONS` | Yes | **`false`** — migrations run via `start.sh` on every deploy |
| `CORS_ORIGINS` | Yes | Must include web Render URL |
| `AI_PROVIDER` | Yes | `openai` (Groq-compatible) |
| `OPENAI_BASE_URL` | Yes | `https://api.groq.com/openai/v1` |

**Never set `SKIP_MIGRATIONS=true` in production.** The API will refuse to start.

## Render Web (`ai-english-teacher-web`)

| Variable | Required | Value |
|----------|----------|--------|
| `NODE_VERSION` | Yes | `20` |
| `NEXT_PUBLIC_API_URL` | Yes | `/api/v1` (same-origin proxy) |
| `API_PROXY_URL` | Yes | `https://ai-english-teacher-api.onrender.com` |

Runtime must be **Node**, not Docker. Root directory: `ai-english-teacher/frontend`.

## GitHub Actions secrets

| Secret | Required for deploy | Purpose |
|--------|---------------------|---------|
| `DATABASE_URL` | **Yes** | Migrations in deploy + migrate workflow |
| `RENDER_DEPLOY_HOOK_API` | Recommended | Force API redeploy after merge |
| `RENDER_DEPLOY_HOOK_WEB` | Recommended | Force web redeploy (fixes stale builds) |

## GitHub variables (optional)

| Variable | Default |
|----------|---------|
| `DEPLOY_WEB_URL` | `https://ai-english-teacher-web.onrender.com` |
| `DEPLOY_API_URL` | `https://ai-english-teacher-api.onrender.com` |

## Validation scripts

```bash
python3 ai-english-teacher/scripts/validate_environment.py
python3 ai-english-teacher/scripts/validate_render_config.py
```

Never commit secrets. Use Render dashboard and GitHub Secrets only.
