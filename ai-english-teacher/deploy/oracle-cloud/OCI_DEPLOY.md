# Oracle Cloud (OCI) Deployment Guide

Deploy the AI English Teacher platform on **Oracle Cloud Infrastructure Always Free** tier — $0/month with enough RAM to run **Ollama** locally.

| Component | Where it runs |
|-----------|---------------|
| Frontend (Next.js) | OCI VM (Docker) |
| Backend (FastAPI + LangGraph) | OCI VM (Docker) |
| Redis (sessions) | OCI VM (Docker) |
| Ollama (local LLM) | OCI VM (Docker, optional) |
| PostgreSQL | [Neon](https://neon.tech) free tier (recommended) |

**Why Oracle Cloud?**
- **4 ARM cores + 24 GB RAM** free forever (Ampere A1)
- Enough power to run Ollama + API + frontend on one VM
- No 15-minute sleep like Render free tier
- You own the server

## Quick Start (3 steps)

### Step 1 — Create Oracle Cloud account & VM

1. Sign up: https://www.oracle.com/cloud/free/
2. Pick your **home region** carefully (cannot change later)
3. Create a compute instance:

| Setting | Recommended value |
|---------|-------------------|
| Name | `ai-english-teacher` |
| Image | **Ubuntu 24.04** (aarch64) |
| Shape | **VM.Standard.A1.Flex** (Ampere) |
| OCPU | **2** |
| Memory | **12 GB** |
| Boot volume | **50 GB** |
| SSH key | Upload your public key |

4. **Open firewall ports** in OCI Console:
   - Networking → Virtual Cloud Networks → your VCN → Security List
   - Add **Ingress** rules:
     - Source `0.0.0.0/0`, TCP port **80**
     - Source `0.0.0.0/0`, TCP port **443**
     - Source `0.0.0.0/0`, TCP port **22** (SSH — usually already open)

5. Note your VM **public IP address**.

> **Capacity error?** Ampere instances are popular. Try a different availability domain, retry later, or use 1 OCPU / 6 GB first.

### Step 2 — Create free database (Neon)

1. Sign up: https://neon.tech
2. Create project `ai-english-teacher`
3. Copy connection string: `postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require`
4. In Neon SQL editor:
   ```sql
   CREATE EXTENSION IF NOT EXISTS vector;
   ```
5. Run migrations (from your laptop or the VM):
   ```bash
   cd ai-english-teacher/backend
   DATABASE_URL="your-neon-url" MIGRATIONS_DIR=../database/migrations python3 scripts/migrate.py
   ```

### Step 3 — SSH into VM and run setup

```bash
ssh ubuntu@YOUR_VM_PUBLIC_IP

# One-command setup (clone + Docker + deploy)
curl -fsSL https://raw.githubusercontent.com/meenakshi25jan/docs/cursor/oracle-cloud-deploy-d164/ai-english-teacher/deploy/oracle-cloud/setup-vm.sh | bash
```

When prompted, edit `.env` and set `DATABASE_URL`:

```bash
nano ~/ai-english-teacher/ai-english-teacher/deploy/oracle-cloud/.env
```

Set at minimum:
```env
DATABASE_URL=postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require
JWT_SECRET_KEY=<auto-generated>
PUBLIC_URL=http://YOUR_VM_PUBLIC_IP
AI_PROVIDER=ollama
OLLAMA_MODEL=llama3.2
```

Then start (if setup didn't already):
```bash
cd ~/ai-english-teacher/ai-english-teacher/deploy/oracle-cloud
docker compose -f docker-compose.oracle.yml --env-file .env --profile ollama up -d --build
```

**Open in browser:** `http://YOUR_VM_PUBLIC_IP`

## Manual Deploy (step by step)

### SSH into VM

```bash
ssh ubuntu@YOUR_VM_PUBLIC_IP
```

### Install Docker

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
newgrp docker
sudo apt-get install -y docker-compose-plugin git
```

### Clone repo

```bash
git clone https://github.com/meenakshi25jan/docs.git
cd docs
git checkout cursor/oracle-cloud-deploy-d164
cd ai-english-teacher/deploy/oracle-cloud
cp .env.example .env
nano .env   # set DATABASE_URL, PUBLIC_URL
```

### Build and start

```bash
docker compose -f docker-compose.oracle.yml --env-file .env --profile ollama up -d --build
```

### Pull Ollama model

```bash
docker compose -f docker-compose.oracle.yml exec ollama ollama pull llama3.2
```

### Verify

```bash
curl http://localhost/health
curl http://localhost/api/v1/health 2>/dev/null || curl http://localhost/health
```

## Environment Variables

| Variable | Required | Example |
|----------|----------|---------|
| `DATABASE_URL` | Yes | Neon connection string with `?sslmode=require` |
| `JWT_SECRET_KEY` | Yes | `openssl rand -hex 32` |
| `PUBLIC_URL` | Yes | `http://123.45.67.89` or `https://yourdomain.com` |
| `AI_PROVIDER` | No | `ollama` (default), `copilot`, `openai`, `mock` |
| `OLLAMA_MODEL` | No | `llama3.2` (needs ~2 GB RAM) |
| `OLLAMA_BASE_URL` | No | `http://ollama:11434` (Docker internal) |

### Use Azure Copilot instead of Ollama

```env
AI_PROVIDER=copilot
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
AZURE_OPENAI_API_KEY=your-key
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

### Use Groq (free cloud LLM, no Ollama needed)

```env
AI_PROVIDER=openai
OPENAI_API_KEY=gsk_xxx
OPENAI_BASE_URL=https://api.groq.com/openai/v1
OPENAI_MODEL=llama-3.1-8b-instant
```

Remove `--profile ollama` from docker compose commands if not using local LLM.

## Add HTTPS (custom domain)

### Option A — Cloudflare (easiest, free)

1. Point your domain A record to VM public IP
2. Enable Cloudflare proxy (orange cloud)
3. SSL/TLS mode: **Flexible** or **Full**
4. Update `.env`: `PUBLIC_URL=https://yourdomain.com`
5. Update `CORS_ORIGINS` in docker-compose or restart backend

### Option B — Caddy with Let's Encrypt

Install Caddy on the host and reverse-proxy to nginx port 80, or replace nginx with Caddy for automatic HTTPS.

## Troubleshooting

### Cannot create Ampere instance ("Out of capacity")

- Try a different **availability domain**
- Retry at off-peak hours
- Start with **1 OCPU / 6 GB** and scale up later
- Use AMD free tier temporarily (1 GB RAM — Ollama won't fit; use Groq instead)

### Site not loading from browser

1. **OCI Security List** — ports 80 and 443 open to `0.0.0.0/0`
2. **VM firewall** — `sudo ufw status` (setup script opens 80/443)
3. **Containers running** — `docker compose ps`
4. **nginx logs** — `docker compose logs nginx`

### Database connection error

- Ensure `DATABASE_URL` includes `?sslmode=require` for Neon
- Run migrations manually (see Step 2)
- Check backend logs: `docker compose logs backend`

### Ollama timeout / slow responses

- First request after pull can take 60+ seconds on 2 OCPU
- Use smaller model: `llama3.2:1b` or `phi3:mini`
- Or switch to Groq/Azure (no local LLM needed)

### `sslmode` TypeError

Already fixed in `backend/app/core/db_url.py` — ensure you're on the latest branch.

### CORS error in browser

Update `PUBLIC_URL` in `.env` to match the URL you're visiting, then:
```bash
docker compose -f docker-compose.oracle.yml restart backend
```
