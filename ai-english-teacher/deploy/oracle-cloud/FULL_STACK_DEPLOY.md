# Full Stack Deploy — Web + Mobile + API on Oracle Cloud ($0/month)

Deploy **everything** on one **Oracle Cloud Always Free** VM:

| Component | How users access it |
|-----------|---------------------|
| **Web app** (Next.js) | `http://YOUR_VM_IP` in browser |
| **API** (FastAPI) | `http://YOUR_VM_IP/api/v1` |
| **Mobile app** (Android) | Points to same API URL |
| **AI** (Ollama) | Runs on same VM (optional) |
| **Database** | Neon PostgreSQL (free, external) |

**Total cost: $0/month** (Oracle Always Free + Neon free tier)

## Step 1 — Create Oracle Cloud VM

**Mumbai (India West) direct link:**  
https://cloud.oracle.com/compute/instances/create?region=ap-mumbai-1

See [VM_SETUP.md](./VM_SETUP.md) for the full click-by-click wizard (all 4 steps).

**Quick settings:**
- Image: **Ubuntu 24.04 Minimal aarch64**
- Shape: Ampere **VM.Standard.A1.Flex** — **1 OCPU / 6 GB** (~50 users + Groq) or **2 OCPU / 12 GB** (Ollama)
- Networking: **Create new VCN** + **Create new public subnet** + **Public IPv4 ON**
- Open ports **80**, **443**, **22** in Security List

---

## Step 2 — Create Neon database (free)

1. https://neon.tech → create project
2. Copy connection string with `?sslmode=require`
3. SQL editor:
   ```sql
   CREATE EXTENSION IF NOT EXISTS vector;
   ```
4. Run all migrations:
   ```bash
   cd ai-english-teacher/backend
   DATABASE_URL="your-neon-url" MIGRATIONS_DIR=../database/migrations python3 scripts/migrate.py
   ```

## Step 3 — Deploy on VM (one command)

SSH into your VM:

```bash
ssh ubuntu@YOUR_VM_IP

curl -fsSL https://raw.githubusercontent.com/meenakshi25jan/docs/main/ai-english-teacher/deploy/oracle-cloud/setup-vm.sh | bash
```

Edit `.env`:

```bash
nano ~/docs/ai-english-teacher/deploy/oracle-cloud/.env
```

```env
DATABASE_URL=postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require
PUBLIC_URL=http://YOUR_VM_IP
JWT_SECRET_KEY=<auto-generated>
AI_PROVIDER=ollama
OLLAMA_MODEL=llama3.2
SKIP_MIGRATIONS=false
```

Start stack:

```bash
cd ~/docs/ai-english-teacher/deploy/oracle-cloud
docker compose -f docker-compose.oracle.yml --env-file .env --profile ollama up -d --build
docker compose -f docker-compose.oracle.yml exec ollama ollama pull llama3.2
```

## Step 5 — Connect mobile app

On your development machine:

```bash
cd ai-english-teacher/mobile
npm install
```

Create `mobile/.env`:

```env
EXPO_PUBLIC_API_URL=http://YOUR_VM_IP/api/v1
```

> Replace `YOUR_VM_IP` with your Oracle Cloud public IP.
> For production Play Store build, use your domain: `https://yourdomain.com/api/v1`

Run on Android:

```bash
npm start
# Scan QR with Expo Go app
```

**Mobile features:**
- Login / Register
- Dashboard (CEFR, IELTS scores)
- Practice with **mic button** → voice analysis + AI chat
- Assessment

### Build APK for Play Store

```bash
npm install -g eas-cli
eas login
eas build --platform android --profile production
```

See [mobile/GOOGLE_PLAY.md](../../mobile/GOOGLE_PLAY.md).

## AI provider options

| Provider | .env settings | Cost |
|----------|---------------|------|
| **Ollama** (on VM) | `AI_PROVIDER=ollama` | $0 |
| **Groq** (cloud) | `AI_PROVIDER=openai`, `OPENAI_BASE_URL=https://api.groq.com/openai/v1` | $0 |
| **Azure OpenAI** | `AI_PROVIDER=copilot`, `AZURE_OPENAI_*` | ~$5-15/mo |

For Whisper voice transcription, use Groq or Azure (Ollama doesn't support Whisper API).

**Recommended for voice:** Groq free tier + Ollama for chat:

```env
AI_PROVIDER=openai
OPENAI_API_KEY=gsk_your_groq_key
OPENAI_BASE_URL=https://api.groq.com/openai/v1
OPENAI_MODEL=llama-3.1-8b-instant
```

## HTTPS with custom domain (optional)

1. Point domain A record → VM IP
2. Use Cloudflare (free SSL) in front of VM
3. Update `.env`: `PUBLIC_URL=https://yourdomain.com`
4. Update mobile `.env`: `EXPO_PUBLIC_API_URL=https://yourdomain.com/api/v1`
5. Restart backend for CORS

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Web not loading | Open port 80 in OCI Security List |
| Mobile can't connect | Set `EXPO_PUBLIC_API_URL=http://VM_IP/api/v1` (not https on raw IP) |
| CORS error | `PUBLIC_URL` in `.env` must match browser URL |
| Voice not working | Use Groq/Azure for Whisper; Ollama is text-only |
| AI slow | First Ollama request takes 60s; use Groq for faster |
| DB error | Run migration 005; check `DATABASE_URL` has `?sslmode=require` |
