# Render — Delete Everything & Create Fresh (AI English Teacher)

Use this when Blueprint/settings are wrong (old branch, `render-backend.yaml`, Docker on web, 404 on `/grammar-class`).

**Keep Neon:** Do **not** delete your Neon database unless you want a empty DB. Copy `DATABASE_URL` before deleting Render services.

---

## Part A — Delete old Render resources

### 1. Open Render

https://dashboard.render.com

### 2. Delete the Blueprint (if present)

1. Left sidebar → **Blueprints**
2. Open **ai-english-teacher** (or any blueprint for this repo)
3. **Settings** → scroll down → **Delete Blueprint**
4. Confirm

This may or may not delete linked services — delete services manually below.

### 3. Delete every Web Service for this project

Left sidebar → **Services**

For each service related to this project, open it → **Settings** → **Delete Service**:

| Delete these if they exist |
|----------------------------|
| `ai-english-teacher-web` |
| `ai-english-teacher-api` |
| `docs`, `docs-wtrv`, or any typo/duplicate |
| Any other test service for `meenakshi25jan/docs` |

Wait until all are removed from the dashboard.

### 4. (Optional) Delete old Neon project

Only if you want a **new** database:

- https://console.neon.tech → delete project → create new → copy new `DATABASE_URL`

Otherwise **keep Neon** and reuse the same `DATABASE_URL`.

### 1. New Blueprint

1. Render Dashboard → **Blueprints** → **New Blueprint Instance**
2. Connect repo: **`meenakshi25jan/docs`**


## Part C — Configure API (`ai-english-teacher-api`)

Services → **ai-english-teacher-api** → **Environment**

| Variable | Value |
|----------|--------|
| `DATABASE_URL` | Your Neon URL with `?sslmode=require` |
| `OPENAI_API_KEY` | Your Groq/OpenAI key (secret) |
| `JWT_SECRET_KEY` | Auto-generated by Render (keep) |

Other vars are set by `render.yaml` (`SKIP_MIGRATIONS`, `CORS_ORIGINS`, Groq URL, etc.).

**Settings → Build & Deploy** (should match blueprint):

| Field | Value |
|-------|--------|
| Branch | `main` |
| Root Directory | `ai-english-teacher/backend` |
| Runtime | **Python** |
| Build | `pip install -r requirements-render.txt` + migrations copy |
| Start | `python3 -m uvicorn app.main:app --host 0.0.0.0 --port $PORT` |

**Manual Deploy** → wait **Live**.

Test:

```bash
curl https://ai-english-teacher-api.onrender.com/health
```

## Part D — Run database migrations (required)

`SKIP_MIGRATIONS=true` on Render — run once from your machine:

```bash
cd ai-english-teacher/backend
export DATABASE_URL='postgresql://...?sslmode=require'
```

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Blueprint only creates API | Blueprint path must be root `render.yaml` (2 services) |
| Web 404 on `/grammar-class` | Web = Node, root `frontend`, deploy with clear cache |
| API 500 / DB errors | Run `migrate.py`, check `DATABASE_URL` |
| CORS errors | `CORS_ORIGINS` must include new web URL on API |
| Wrong Dockerfile on web | Runtime → Node; remove Docker settings |
